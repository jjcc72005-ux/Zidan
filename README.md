# 🚀 محول HTML إلى APK

مشروع كامل لتحويل أي كود HTML أو موقع ويب إلى تطبيق أندرويد (APK) - يعمل مباشرة من GitHub! 

## 🌟 المميزات

- ✅ **تحويل HTML إلى تطبيق**: حول أي كود HTML إلى مشروع تطبيق جاهز
- ✅ **تحويل المواقع إلى WebView**: حول أي موقع ويب إلى تطبيق أندرويد
- ✅ **واجهة عربية**: واجهة مستخدم باللغة العربية سهلة الاستخدام
- ✅ **يعمل على GitHub**: لا حاجة لتثبيت أي برامج
- ✅ **مجاني 100%**: لا توجد أي تكاليف

## 🎯 كيف يعمل؟

1. **أدخل كود HTML** أو **رابط موقع**
2. **انقر تحويل** لإنشاء مشروع التطبيق
3. **استخدم المنصات المجانية** لبناء APK

## 📱 طرق بناء APK

### الطريقة 1: PhoneGap Build (موصى به)
1. اذهب إلى [build.phonegap.com](https://build.phonegap.com)
2. سجل حساب مجاني
3. ارفع ملف `config.xml` و `index.html`
4. انتظر اكتمال البناء
5. حمّل ملف APK النهائي

### الطريقة 2: Cordova (للمطورين)
```bash
npm install -g cordova
cordova create myapp
cd myapp
# استبدل ملف www بمحتوى المشروع
cordova platform add android
cordova build android
